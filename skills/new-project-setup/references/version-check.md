# Version Check (Latest Policy)

## Purpose

A short policy for using "latest" or "latest LTS" and how to verify it.

## Basic policy

- When possible, verify with official documentation or release notes.
- If external information is not accessible, ask the user to confirm or mark it as unverified.

## Targets

- Rust: stable + edition 2024
- Node.js: latest LTS, pinned in `.nvmrc`
- TypeScript/libraries: latest stable
- Hono/Vite/NestJS/Next.js: latest stable

## Output examples

- "Use the latest stable version (verify with official release notes if needed)."
- "Pin Node.js to the latest LTS in `.nvmrc`."
- "Latest version is unverified; please confirm via official docs."
